- 改造交互：点击部件先预览完整效果，再点“确认选用”写入待改造方案，最后“动手改造”才持久化；分页按钮固定绘制在模态层。
- 英雄全身改造：已拥有英雄也可进入改造台，核心、头部、肢臂、足部四个部位均可替换；改造后的外观与部件数值会同步作用于名册、房间布阵和战斗。英雄改造的骨币、魔质与传奇遗物消耗均为怪物改造的两倍，旧存档自动兼容。
- 传奇部件：新增每类两件、合计 8 件传奇部件；装配需要英雄遗物，遗物可在工坊用 5000 骨币与 5000 魔质熔铸，或击倒勇者时低概率缴获。
- 内容扩充：部件库增至 148 件（含 56 件物种专属部件与 8 件传奇部件）；固定缴获装备由 27 件扩充到 36 件并加入神话档，仓库容量同步提高到 18。
- 视觉与对白：满级英雄/怪物在名册、布防、怪群卡片与战斗小人上显示动态金色闪光；勇者队伍进房时新增双人黑色幽默对话，同时进入日志与头顶气泡。
- 战斗对白与战报：普通攻击、按技能性质分类的主动技能、结合“伤害/总生命”与“伤害/当前生命”的分级受伤、治疗恢复，以及反伤、溅射、吸血、直击后排、复活、拉起队友、施毒和燃烧均有独立对白池。对白按单位节流且战报单独留存；战报新增攻防次数、重击、伤害、治疗、特殊效果、击倒数、逐房纪事与更具叙述感的战术复盘。
- 立绘一致性：剑圣源立绘已无损水平翻转为正确朝向；地牢部署格、部署候选、名册、已拥有列表与战斗统一读取实例最终纹理，英雄与怪物改造后不再回退到基础立绘。

- 装备交互：装备槽与仓库装备卡的完整视觉区域均可点击，避免点击卡片下半部仍沿用旧槽位；“详情/详”、熔炼和改锻按钮保持独立且优先响应。
- 怪物说明：创造/重组时的已选词缀提供双行摘要和全文详情；招募预览与已拥有怪物详情中的被动统一在固定边界内自动换行，点击区域可查看完整文本。
- 小屏适配：启用刘海安全区、动态视口和最高 2× 高像素密度渲染；手机横屏自动安全缩放，竖屏可点按尝试全屏锁定横屏，旋转过程中战斗与经营界面的引导层即时同步。
- 触控与输入：紧凑像素按钮提供受限的最近目标触控补偿；创造、锻造、造词和剧情原生输入框在小屏保持至少 22px 高度与 16px 字号，避免软键盘触发页面缩放。

- 情境秘闻一期：秘闻从随机独立事件扩展为“经营行为产生线索—对应页面追查—选择影响现有玩法—结果进入档案”的闭环。七类设施建成、英雄疗愈/四战轮休、后勤房遭劫、工作人员倒下和英雄复活均可产生专属线索；设施、英雄与战报页面会显示直接入口，秘闻页统一展示最多24条待处理线索与最近20条档案。旧存档会自动补齐状态并为已有设施补发专属线索。
- 情境秘闻二期：英雄全身改造、学习专精、启用称号，以及设施升级和重损修复均接入专属事件。线索支持按袭击轮次延迟成熟，第一期的魔力井倒影、旧伤倾诉和留守者纪念等选择可在两轮后产生回响；新增英雄/设施定向剧情效果，确保经验、休息、伤势、耐久和维修点落到实际触发对象。战报会记录本场生效的秘闻修正与本轮已解决回响。
- 情境秘闻三期：英雄共同出战会积累友谊、竞争或师徒关系，训练场会记录同窗与跨物种授课，遣退英雄会保留完整离队档案并在后续袭击后寄回书信；达到组合历史条件时可触发地牢纪念日、活体廷议和流亡者归队等稀有多人事件。
- 设施性格：后勤房会按反复受损、维修、升级或连续值守形成“伤痕累累、坚韧、进取、勤勉”等永久性格，获得稳定昵称与最多24条本设施履历；性格会实际影响产出、低耐久效率、工作人员效率或抗劫掠能力，拆除后才随设施消失。
- 地牢编年史：秘闻归档不再限制最近20条；可按英雄、设施、战后和稀有事件分类，也可从具体英雄、设施或某轮战报进入定向筛选。战场修正保存来源秘闻编号，战报与秘闻档案建立双向跳转。
- 旧事件长链：原有随机事件不再解决后即消失，全部写入永久档案；原本没有连续幕的事件均增加延迟两至三轮的专属回响，已有即时第二幕的记账兵、工坊低语与俘虏事件继续保留。英雄改造、传奇改造、攻击/防御/指挥专精和战斗/生还/指挥称号各自使用独立文本。
- 秘闻影响反馈：选择结算后的绿色结果会同时显示变化名称、持续轮数和完整战斗数值，例如怪物生命、怪物攻击、勇者生命、勇者攻击、封印、陷阱或房间限时的具体增减；档案会保存同一份明细，不再只显示“某变化持续3轮”。
- 无主秘闻入口：有次数时可直接追查；次数为0时不再表现为无反馈的禁用按钮，点击会明确说明胜利补充2次、失守补充1次。外部叙事接口异常时自动回落本地事件池，避免入口长时间无响应。
- 详情弹层隔离：魔物招募与已拥有列表中的技能不再使用覆盖原页面的局部小卡片，统一进入独占详情层；所有共用详情弹层打开时暂停绘制背后页面和其他模态，关闭后恢复，彻底避免两层文字与卡片重叠。
- 设施立绘：骨料场、魔力井、训练场、疗愈池、工坊、孵化室和宝库均拥有独立透明像素素材；统一采用无俯视、无透视、看不到顶面的正侧立面，并同时用于地牢经营卡片和战斗房间。
- 建设节奏：每个袭击轮次共享一次建设机会，建造或升级任一设施后，本轮其余建造与升级按钮锁定；维修、人员指派和训练管理不占用机会。
- 入侵者扩充：新增炼金术师、武僧、枪骑兵和咒术师四种独立职业与立绘，分别提供群体中毒、治疗护盾、前后排贯穿和咒火延迟技能。
- 秘闻限流：线索按英雄、魔物和具体设施建立主体标识，同一主体在同一轮最多生成一条秘闻，避免一场战斗后同一对象连续刷出多条线索。
- 工程化：仓库新增统一的 `npm start`、`npm run check`、`npm run smoke` 和 `npm run verify`。浏览器冒烟测试直接驱动本地 Chrome/Edge，覆盖旧存档升级、随机秘闻归档、多人关系、设施性格、真实战斗结算、战报回链、流亡英雄、受限文本和小屏布局。
